# Северный Контур — Академия безопасности

Платформа обучения по информационной безопасности: курс из 7 недель, уровни, звёзды, бейджи,
ежедневный вопрос, повторение ошибок, итоговый экзамен с сертификатом и кабинет администратора компании.
Дизайн, тексты и Черепундель взяты из вашего HTML-прототипа без изменений.

## Быстрый старт

```bash
./run.sh            # Linux/macOS (создаст .venv, поставит зависимости, запустит)
run.bat             # Windows
```

Откройте http://127.0.0.1:8000. База создаётся сама в `data/academy.db`.

Посмотреть кабинет администратора на готовых данных:

```bash
python manage.py seed-demo      # демо-компания, 24 сотрудника
# админ: admin@severny-kontur.ru   сотрудники: user1@severny-kontur.ru ... user24@severny-kontur.ru
# пароль у всех: Demo-Pass-2026    код компании: DEMO2026
```

Демо-данные нужны только для показа, в рабочую базу их не загружайте.

### Docker

```bash
docker compose up -d --build
```

База хранится в `./data`, делайте с неё резервные копии. Перед публикацией в интернет поставьте
перед сервисом HTTPS (nginx, Caddy, Traefik) и задайте `COOKIE_SECURE=1`.

## Как это работает для людей

Регистрация предлагает три пути:

| Путь | Что получается |
|---|---|
| **Новая компания** | Создаётся компания и её администратор, задаются подразделения. Администратор получает **код компании**. |
| **Я сотрудник** | Сотрудник вводит код компании, выбирает подразделение и попадает в свою организацию. |
| **Учусь сам** | Человек без компании. Все уровни, награды и сертификат работают так же. |

Все, что человек заработал (звёзды, очки, уровень, бейджи, серия дней, точность по темам, сертификат), хранится в базе
и привязано к аккаунту. После перезагрузки или входа с другого устройства прогресс на месте.

### Правила игры (как в прототипе)

* Урок: доверие отдела 100%, за каждую ошибку −20%. Засчитывается при 60% и выше, **и** если верно не меньше половины ответов
  (иначе урок из двух вопросов нельзя было бы провалить).
* Звёзды: 1 за прохождение, ещё 1 при доверии от 90%. Если прошли хуже, повторите урок: недостающая звезда начислится.
* Вопрос дня: 1 звезда и 20 очков за верный ответ. Вопросов 14, они сменяются по дням.
* Уровни: пороги 0, 3, 7, 12, 18, 25, 33, 42 звезды. Недели 1 и 2 открыты сразу, неделя N (с 3-й) открывается на уровне N.
* «Повторение ошибок» открывается на уровне 2: вопросы, в которых ошиблись, возвращаются через 48 часов.
* Итоговый экзамен на уровне 8: 14 случайных вопросов (по 2 из каждой недели), нужно 80%, без подсказок. Дает 2 звезды, 200 очков и сертификат.
  У сертификата есть номер и публичная страница `/certificate/<номер>`: ее можно распечатать и проверить подлинность.
* Серия дней считается по часовому поясу человека.

## Кабинет администратора

Кнопка «Для администратора» видна только админам компании.

* **Обзор:** прогресс по подразделениям, где чаще ошибаются, сколько человек прошли каждую неделю, активность за 14 дней.
* **Сотрудники:** прогресс, подразделение, роль, отключение, **сброс пароля** (временный пароль показывается один раз,
  при входе сотрудник обязан придумать свой), выгрузка CSV (открывается в Excel).
* **Подразделения:** добавить, переименовать, удалить.
* **Настройки:** код приглашения (можно выпустить новый), разрешённый домен почты, режим открытия недель.

**Режим открытия недель.** «По уровням» это игровая механика прототипа. Для обязательного обучения со сроком включите
«По порядку»: следующая неделя открывается после предыдущей, а экзамен после всех семи. Тогда никто не застрянет из-за нехватки звёзд.

**Приватность заложена в устройство.** Администратор видит прогресс людей (сколько уроков, когда заходили), но не их ответы и ошибки.
Сводка ошибок показывается по темам и только если ответили минимум 3 человека, иначе по ней можно было бы вычислить одного сотрудника.
Командный зачёт считает очки подразделений, а не людей.

## Материалы

Теперь у **каждого** урока и **каждой главы** сюжета есть страница «Материал» (что это, зачем, как работает, пример из жизни).
В прототипе её не хватало у четырёх глав сюжетов (недели 1, 2 и 3): они дописаны. Кроме того:

* у каждого урока в списке недели есть кнопка **«Материал»**: прочитать можно в любой момент, без прохождения;
* внизу недели лежит памятка «Что запомнить»;
* закрытые недели и уроки кликабельны и объясняют, чего не хватает для открытия;
* карточка итогового экзамена и узлы на «пути по курсу» кликабельны.

```
  services.py       уровни, звёзды, серия дней, расчёт прогресса, награды
  content.py        загрузка курса, ответы клиенту без правильных вариантов
  routes_auth.py    регистрация, вход, профиль
  routes_learn.py   уроки, ответы, вопрос дня, повторение, экзамен, сертификат
  routes_admin.py   кабинет администратора
  content/course.json   весь учебный контент (недели, уроки, вопросы, вопрос дня)
  tests/            автотесты (python -m unittest backend.tests.test_api)
frontend/           статический интерфейс без сборки (HTML, CSS, JS) и 8 поз Черепунделя

```

### База данных (SQLite)

`orgs`, `departments`, `users` (звёзды, очки, роль, часовой пояс), `sessions`, `lesson_progress` (лучшее доверие, звёзды, попытки),
`badges`, `answers` (каждый ответ: основа для точности и повторения), `xp_log` (журнал начислений), `activity_days` (серия),
`daily_answers`, `runs` (незавершённые прохождения), `exam_attempts`, `certificates`, `login_attempts`.

### API (кратко)

| Метод и путь | Что делает |
|---|---|
| `POST /api/auth/register`, `/login`, `/logout`, `GET /api/session` | аккаунт и сессия |
| `GET /api/bootstrap`, `/api/progress` | курс и прогресс текущего человека |
| `GET /api/lessons/<ключ>` | материал и вопросы урока **без правильных ответов** |
| `POST /api/lessons/<ключ>/start`, `/api/runs/<id>/answer`, `/hint`, `/hit`, `/finish` | прохождение: ответ проверяет сервер |
| `GET /api/daily`, `POST /api/daily/answer` | вопрос дня |
| `GET /api/review`, `POST /api/review/answer` | повторение ошибок |
| `GET /api/exam`, `POST /api/exam/start` | итоговый экзамен |
| `GET /api/team` | командный зачёт подразделений |
| `/api/admin/...` | обзор, сотрудники, подразделения, настройки, `export.csv` (только админ) |

Правильные ответы остаются на сервере и показываются только после ответа, поэтому очки и сертификат нельзя накрутить, открыв консоль браузера.

## Безопасность

Пароли хэшируются (scrypt). Сессия лежит в HttpOnly-cookie (SameSite=Lax), на сервере хранится только хэш токена.
Вход ограничен по числу неудачных попыток, регистрация по числу с одного адреса. Запросы с чужого Origin отклоняются.
Все данные пользователей экранируются при выводе. Администратор не может отключить или разжаловать последнего админа и работает только в своей компании.

Чего здесь нет и что стоит учесть при выходе в продакшен:

* **Восстановление пароля по почте.** Нужна отправка писем (SMTP). Пока пароль сбрасывает администратор компании, а для одиночных
  аккаунтов `python manage.py reset-password почта`.
* **Content-Security-Policy.** Интерфейс использует встроенные обработчики кликов, поэтому строгий CSP потребует небольшой переделки.
* **Шрифт Onest** подключается с Google Fonts, как в прототипе. В закрытом контуре без интернета подставится системный шрифт; при желании положите файлы шрифта в `frontend/` и поправьте `<link>`.
* **SQLite** выдерживает сотни одновременных сотрудников. Для тысяч и нескольких серверов стоит перейти на PostgreSQL (SQL здесь простой, переход затрагивает `db.py`).
* **Учебные фишинг-рассылки.** Блок «учебная проверка» из прототипа содержал выдуманные цифры, настоящей рассылки за ним не было, поэтому я его не переносил:
  он потребует почтового сервера и согласования с вашим ИТ.

## Как менять курс

Весь контент в `backend/content/course.json`: недели, уроки, главы, материалы, вопросы, вопросы дня. Типы вопросов:
`one` (один ответ), `tf` (верно/неверно), `multi` (несколько), `sort` («можно/нельзя» для каждого пункта).
Правильный ответ: число для `one`/`tf`, список номеров для `multi`, список 0/1 для `sort`. После правки перезапустите сервер.
Ключ урока `неделя.номер` (например `3.1`) сохраняйте: по нему записан прогресс людей.
